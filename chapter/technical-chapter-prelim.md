# 工作章「预备知识」撰写

## 核心原则

**预备知识只给后文要用的符号与已有工具，不写本章方法，不与相关工作章抢综述。** 好的预备知识让读者在方法设计节遇到符号和工具时不回翻，同时知道每个工具为何被选用。

### 六条铁律

1. **只给后文要用的定义。** 符号、已有方程、对比损失、矩阵分解等，后文方法节会引用的才写。不要为完整而铺开。
2. **不写本章方法。** 本章贡献放到对应工作节。预备知识里最多一句"该原则在本章用于……"。
3. **不与相关工作章抢综述。** 相关工作章写谱系与空白；本章预备知识写工具本身（公式与符号）。
4. **公式后写"式中"。** 与方法设计同一体例。
5. **主语用"本章"。** 不用"本文"。
6. **行文遵守入口通则。**

---

## 三层结构

### 第一层：帽子段落（1 句）

概括本节将介绍哪些预备知识，点出为后续方法设计提供理论基础。

```
本节介绍【条目1、条目2、条目3】等预备知识，为后续方法设计提供理论基础。
```

列出全部预备知识条目名称，用工具名而非泛称。

### 第二层：任务定义类

给出后文要用的任务定义与核心符号。每条以 `\textbf{条目名}。` 开头。

- **只说任务是什么**：输入、输出、目标，用核心符号表达。
- **不介绍数据集和评测指标**：留给实验分析节。
- **说清模型要做什么**：如果只给任务定义说不清模型的工作，可加一两句话说明模型需要做的事情。
- **数据结构定义也算任务定义类**：给出符号即可。

```
\textbf{【任务名】}。给定【输入与符号】，任务是【输出】。在实现上，训练阶段……；测试阶段要求模型【做什么】。
```

无数据集名、无评测指标，只给任务定义 + 符号 + 模型要做什么。

### 第三层：理论基础类

给出后文要用的已有理论与工具。每条以 `\textbf{条目名}。` 开头，按"动机引入→思路→公式→符号→联系"五步展开。

| 步骤 | 内容 | 写法 |
|------|------|------|
| 动机引入 | 该理论的来源、动机或要解决的问题 | "旨在寻找……，其核心动机是……" |
| 思路 | 该理论的核心思路 | "给定……，寻求……在……的同时……" |
| 公式 | 核心公式 | `\begin{equation}\label{eq:prelim-xxx}…\end{equation}` |
| 符号 | 解释公式中符号 | "式中，$\beta>0$ 为权衡系数；$I(Z;X)$ 为……" |
| 联系 | 该工具与本章方案的关系 | "该原则在本章用于……" |

**动机引入**：一句话点出"为什么需要这个工具"，不展开历史。若后一个工具服务于前一个，可引用前式："式~\eqref{eq:prelim-xxx} 中的……均难以直接计算"。

**联系句**：一句话点出"本章用它做什么"，不展开方法细节。

**注意**：

- 公式后必须用"式中"解释符号，与方法设计节同一体例。
- 若一个工具需要多个公式，可连续给出，每个公式后各跟"式中"。
- 前一章已定义的记号可写“见第~\ref{chap:xxx}~章式~\eqref{…}”，不重出编号。

## 常见问题

### Q：预备知识要不要介绍数据集和评测指标？

**不要。** 留给实验分析节。若只给任务定义说不清模型的工作，可加一两句话说清模型要做什么。

### Q：理论基础类要不要写动机引入？

**要。** 每条以动机引入开头，一句话即可，不展开历史。

### Q：理论基础类的联系句怎么写？

**一句话点出"本章用它做什么"。** 不展开方法细节，不写公式。

### Q：一个理论需要多个公式怎么办？

**可连续给出多个公式，每个公式后各跟"式中"。** 若后一个公式是前一个的实现，动机引入可引用前式。

### Q：预备知识里的符号与方法设计节的符号要不要一致？

**要一致。** 预备知识定义的符号在后文直接引用，不能换符号。若预备知识用通用符号，方法设计节可将通用定义代入具体变量，但符号体系须对应。
