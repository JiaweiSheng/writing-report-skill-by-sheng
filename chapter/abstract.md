# 摘要（中英文）

## 核心原则

**摘要是全书的独立代理：不读正文也能知道研究什么、为何难、按哪几条任务做了什么、各做到哪一步。** 好的摘要让读者在总述段看清“热点—旧设定不够—现有仍面临什么—本文对象与做法”，再在分条里按柱看到“开展哪项章题、提出何种方法、关键机制是什么、提升了何种能力”，并且用的是绪论已锁的同一套词。框架未锁时不要写摘要，先走 [研究框架](research-framework.md)。

学的是**两块结构**（总述漏斗 + 按任务分条）。柱数、锁词、机制词从当前稿台账取，不要为迁就范例而改柱数或挑战名。条内不写“针对【具体难点】”。

### 六条铁律

1. **两块成文，先总述后分条。** 总述一段（句1–3 分写；句4 焊成一句；句5 用“具体来说，”收束）；随后按柱分条；最后 `\keywords` / `\KEYWORDS`。不要写成背景—问题—每章带数字—意义的一段流水账，也不要单开“结论与意义”句。
2. **分条两层定位，按柱不按论文篇数。** 方面短名、开展章题全称、总述中名三层不得叠床。同一工作章内多项工作仍收在同一条，不要按论文篇数拆条。
3. **条内三拍排比，不报数字。** 每项工作固定：提出一种【基于机制的方法/框架】，通过【机制要点】，有效提升了【具体能力或任务性能】。不要在条内写“针对【具体难点】”。效果宾语落到任务或机制，禁止“验证了有效性”，禁止准确率、Hits@k、MRR、百分点。数字留给工作章与结论。
4. **锁词与绪论同词，不另起近义。** 条件术语、对象、整体难点、机制词、主线见当前稿台账。总述挑战用**整体难点**。互为依据句、各柱具体难点不进摘要。方法用中文机制表述，摘要不堆英文简称。
5. **中英文同一套 moves，不逐字对译。** 信息不增不减、柱序相同；英文可调语序。中文说“主要包括以下内容”，不要改成“主要贡献 / 创新点”。英文用 `This paper` / `This report`，不要 `we`。无公式、无图表、无 `\cite`。
6. **主语“本文 / 本报告”，完成体。** 这是全书层。禁止“拟研究 / 本项目 / 申请人”。禁止空夸“填补空白、国际领先、研究热点很少”。

## 改定经验（须守）

以下条款来自摘要成稿改定。写或改摘要时先按此对表，再动句子。润色不得把已锁定骨架改回旧句模。

### 总述不写互为依据

摘要只写对象 + 做法 + 旨在提高能力。不要为“对应链完整”把绪论里的互为依据 / 关系句写进摘要。该句仍锁在绪论与（若需要）结论。

### 句4 焊成一句，句5 用“具体来说，”

```
基于此，本文面向【对象】，研究【做法】，旨在提高【目标】在【锁定条件】下的能力。
具体来说，本文主要围绕【中名1、中名2、…】【N】个核心任务展开研究，主要包括以下内容：
```

不要拆成对象句、互为依据句、旨在句三句。不要删“具体来说，”。不要把句5 中名改成分条短名（缺“学习 / 建模”一类任务类后缀）或章题全称（多了限定词）。

### 分条两层定位，条内不写针对

```
（n）在【短方面名】方面，开展【章题全称】研究：首先，提出一种……，通过……，有效提升了……；
其次，提出一种……；
最后，提出一种……。
```

| 层 | 用词 | 位置 |
|---|---|---|
| 中名 | 带任务类后缀（学习 / 建模 / 检测 / 抽取等） | 总述句5 |
| 短名 | 去掉限定词与任务类后缀后的方面名 | “在……方面” |
| 全称 | 工作章章题 | “开展……研究” |

不要写成“在【中名】方面，开展【全称】研究”（中名与全称叠床）。不要把“首先，针对【具体难点】，提出”写回分条。难点只出现在总述句3 的整体难点。

### 失败经验（不要再写回去）

- 每章一句带数据集名 / Hits@k / MRR 等数字
- 总述单列互为依据句
- 条内“针对【具体难点】”
- 方面名只用中名或只用全称一套，与句5、开展研究不对层
- 把当前稿柱数压成范例文本的柱数，或把条内改回“针对—提出—通过—提升”四拍

## 逻辑结构

```text
总述段
  句1  随着【宏观发展】→【观测数据/现象增长】→ 如何在【锁定条件】下【研究目标】已成为当前的研究热点
  句2  传统方法主要聚焦于【旧设定】，无法有效应对【现实新场景】
  句3  尽管现有方法已有进展，但仍面临【整体难点】等多方面的挑战
  句4  基于此，本文面向【对象】，研究【做法】，旨在提高【条件】下的能力
  句5  具体来说，本文主要围绕【各柱中名】【N】个核心任务展开研究，主要包括以下内容：

分条（各占一段）
  （1）在【短名】方面，开展【章题全称】研究：首先，提出一种…；其次，提出一种…；最后，提出一种…
  （2）（3）… 同构

关键词
```

句3与句4不要焊成一句。句4 内部可以“面向…，研究…，旨在…”一气呵成，但不要再塞互为依据。句5 必须“具体来说，”起句，收束到中名，不要在总述里预告方法名。

成文只分“总述一段 + 各条各一段”，不要按句号把总述拆成五段。

## 总述：五句功能与句模

句模见下；常见病句见文末“不要学的原文毛病”。

### 句1 热点（背景 → 数据 → 问题）

```
随着【技术/应用】的快速发展及广泛应用，【载体】中的【观测形态】也随之急剧增长，如何从【数据困境】中 / 在【锁定条件】下【完成目标】已成为当前的研究热点。
```

条件术语必须按台账成对或整组出现，不要缩成口号。观测/数据须带中心语。不要写“随着……使得……也随之”（双重因果）。

### 句2 传统不足

```
传统的【任务族】方法主要聚焦于【旧设定】，无法有效应对现实中【新场景特征】。
```

旧设定要能反衬后文各柱，不要只骂一个已被放弃的窄设定。

### 句3 进展 + 仍面临的挑战

```
尽管现有【任务族】方法已经取得了部分进展，但仍面临【整体难点1、2、…】等多方面的挑战。
```

挑战名用台账**整体难点**原词，不要写成各柱具体难点，也不要写成范例文本的挑战名。“尽管”后不加逗号。

### 句4 基于此，面向—研究—旨在

```
基于此，本文面向【对象】，研究【做法】，旨在提高【目标】在【锁定条件】下的能力。
```

对象句必须与台账原词。不要把做法写成研究对象。不要句末赘“能力的”。不要在此插入互为依据句。不点方法名。

### 句5 范围收束

```
具体来说，本文主要围绕【中名1、中名2、…】【N】个核心任务展开研究，主要包括以下内容：
```

中名带任务类后缀，与分条短名、开展全称分层。必须保留“具体来说，”。

## 分条：开展章题 + 提出—通过—提升

### 多项工作（该柱默认）

```
（n）在【短方面名】方面，开展【章题全称】研究：首先，提出一种【基于机制A的方法】，通过【机制要点A】，有效提升了【效果A】；其次，提出一种【基于机制B的方法/框架】，通过【机制要点B】，有效提升了【效果B】；最后，提出一种【基于机制C的方法】，通过【机制要点C】，有效提升了【效果C】。
```

各项用中文分号连接，末项句号。不要用“一是 / 二是”，不要 `\enumerate`。不要在首先/其次/最后里写“针对”。该柱若只有两项，改为首先 / 其次；若只有一项，见下。

### 一项工作（仅当该柱确只有一项）

```
（n）在【短方面名】方面，开展【章题全称】研究：提出一种【基于机制的方法】，通过【机制要点】，有效提升了【效果】。
```

### “提出一种”怎么命名

优先用绪论组织节的节题改写成“基于【机制】的【任务】方法 / 框架”：

- 提出一种基于【机制】的【任务】方法
- 提出一种基于【机制】的【框架类型】
- 提出一种基于【机制1和机制2】的统一【任务】框架

“有效的 / 新的”每条至多用一次，不要各条都加。不写英文括号缩写。

### “通过”怎么写机制

只写关键变换，不写公式、模块清单式编号：

- 分别从【视角1】和【视角2】实现【目标】
- 通过【机制】【保留/剥离/刻画】【对象】
- 将【X】作为【先验/约束】，经【机制】得到【Y】
- 同时完成【对象1】与【对象2】的【关系类型】

机制词与台账、章引言工作句同一套。

### “有效提升了”怎么写效果

宾语必须具体，形成排比但不要各条都用同一个“性能”：

- 有效提升了【任务】的准确性 / 泛化性 / 鲁棒性
- 有效提升了【机制所针对的能力】

禁止“验证了本方法的有效性”。禁止把本章小结里的指标数字写进摘要。

## 关键词

`\keywords{词1，词2，……}` 与 `\KEYWORDS{English, ...}`。

- 6–10 个；中文用逗号 `，` 分隔，不要顿号。
- 由面到点：目标 → 做法两半 → 各柱任务名 → 2–3 个可检索任务别名。
- 不要重复封面题目整句；不要堆方法简称。
- 英文 Title Case，词序与中文对应。

## 英文摘要

与中文同一套 moves，写在 `\intobmk\chapter*{Abstract}` 下。

**总述对应：**

- 句1 `With the rapid development and widespread application of ...`
- 句2 `Traditional ... methods primarily focus on ..., failing to ...`
- 句3 `Although existing ... methods have made some progress, they still face ...`
- 句4 `To address these issues, this paper studies ... for ..., aiming to ...`
- 句5 `Specifically, this paper focuses on [N] core tasks: ..., with the following main contents:`

中文“包括以下内容”不要改成贡献清单；英文可用 `main contents`，不要改成 `innovations`。条内用 `In 【short name】, this paper conducts research on 【full chapter title】: first, a ... method is proposed, ... which effectively improves ...; second, ...; finally, ...`。不要写 `addressing ...`。

禁止 `we propose`。完成体用现在完成或一般现在（`proposes` / `is proposed` / `improves`），不要未来时。

## 对应链

写之前先锁下表（内部草稿，不写入 `.tex`）。表建不成，不要开始改句子。取值来自当前稿台账。

| 摘要槽位 | 必须对上 |
|---|---|
| 句1 条件与目标 | 台账锁定条件与研究目标 |
| 句4 对象与做法 | 台账对象；做法不是对象。互为依据不进摘要 |
| 句3 挑战 | 整体难点原词 |
| 句5 中名 | 各柱中名 |
| 分条短名 + 开展全称 | 短名见改定经验；全称 = 各工作章章题 |
| 条内提出 / 通过 | 组织节节题 + 台账机制词；不写成果英文简称；不写针对具体难点 |
| 条内提升 | 任务或机制能力；不报数字 |
| 主线 | 分条顺序必须与台账主线同向 |

摘要压缩绪论研究内容，不压缩结论的未来工作。不要出现“下一步 / 展望”。

## LaTeX 槽位

只改 Frontmatter 中文摘要段与英文摘要段。保留 `\intobmk\chapter*{摘\quad 要}`、`\keywords`、`\KEYWORDS` 与页码设置。

- 总述连续若干句，句末换行；句5 以“具体来说，……包括以下内容：”收束。
- 空一行后写（1）段，再空一行（2），依此类推。
- 不要 `enumerate` / `itemize`。
- 中英都不放公式、图、表、`\cite`。

下列病句不要写入 `.tex`：

| 原文问题 | 改为 |
|---|---|
| “随着……使得……也随之” | 只保留“随着……也随之”，或只保留“使得” |
| “尽管，现有” | “尽管现有”，尽管后不加逗号 |

| 旨在句末“能力的” | 删赘字“的” |

| 每条带准确率 | 按本文件不报数字 |
| 条内“针对【具体难点】” | 改为开展章题；针对只留在总述整体难点 |

## 写作顺序

1. 按对应链表核对当前稿台账（条件、对象、各柱中名/短名/全称、整体难点、机制、组织节节题）。互为依据与具体难点用于核对后文，不写入摘要。
2. 写总述：句1–3 分写，句4 焊成一句（无互为依据），句5 用“具体来说，”+ 中名。
3. 按柱写各条：短方面名 + 开展章题 + 首先/其次/最后；不要写针对。
4. 写关键词；再写英文，按 moves 对表，不逐字翻译；英文条内不要 `addressing`。
5. 反向校验：无数字、无简称堆砌、无未来工作、无条内具体难点。
6. 过 [polish/academic-zh.md](../polish/academic-zh.md)。不得把“具体来说，”“在……方面，开展……研究：”“首先 / 其次 / 最后”“主要包括以下内容”改掉。

用户只改中文或只改英文时：先对表，再只动那一侧，最后补另一侧对应，避免中英各说一套。

## 常见问题

### Q：摘要和绪论、结论有什么区别？

**摘要**是开门代理，两块分条，不展开统计与框架图。**绪论**是漏斗，背景与意义分成两个 `\section`。**结论**按柱收回贡献并写未来。摘要不写展望，也不复制绪论研究问题的图与统计。

### Q：为什么不报数字？

分条以机制与能力收束。用户当场要求带主证据数字时，每条至多一句、口径与各章主表一致，仍禁止把本章小结整段指标搬进来。

### Q：为什么分条不写“针对【具体难点】”？

难点只出现在总述句3 的整体难点；分条用开展章题定位，条内只写提出—通过—提升。具体难点留给绪论与工作章。

### Q：互为依据为什么不进摘要？

摘要只写对象、做法与旨在提高能力。互为依据句仍锁在绪论与结论，不要为对应链把该句写回摘要。

### Q：中文“内容”英文能不能写 contributions？

总述收束保持“内容 / contents”。不要因此把摘要改成绪论贡献条的英译，也不要出现“创新点”。
