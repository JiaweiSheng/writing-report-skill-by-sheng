# 工作章「本章小结」撰写

## 核心原则

**本章小结是全章的收束，回答三个问题：本章因何种现实需求而展开、做了哪几件事、为整个研究报告主题发挥什么作用。** 好的本章小结让读者在 300–400 字内回顾全章脉络，记住每项工作的核心贡献与量化效果，并知道本章在全书中的定位。若干项工作时小结易超长，须按下方压缩技巧精简。

### 六条铁律

1. **六层叙事，逐句换行。** 现实需求+分析 → 难点 → 为此开展研究 → 首先/其次/最后（每项：技术→性质/效果→量化）→ 为整体主题提供作用。每句独占一行，一句一意。
2. **难点用"然而…导致…同时…导致…"句式。** 不用"一是/二是"列举，用因果句把现象与难点连起来，更紧凑。
3. **每项工作 2–3 个子句，简洁。** 句式：提出xxx，通过/利用xxx（技术），实现/达到xxx（效果），在xx任务上量化。不展开方法细节，不重述公式。
4. **不写英文括号缩写。** 本章小结中方法名只用中文，不加英文括号缩写（前面已出现过）。基线方法名保留。
5. **量化同时报绝对指标与相对指标。** 绝对：于xx取得 xx% 准确率；相对：相对次优方法提升 xx%。标明任务名与指标名。不写"百分点"，直接写"x%"。最好是所有数据集的平均相对提升。
6. **末句只写对整体主题的作用。** 说明本章为整个研究报告主题提供什么基础，可用任务名简要提及后续研究点，但不写"第几章"。

## 六层结构

### 第一层：现实需求+分析（1 句）

从本章对象的现实需求起笔，点出场景与挑战。

```
【对象】作为【应用领域】广泛存在的……，其【真实场景特征】给【本章任务】带来挑战。
```

一句话含"对象+应用领域+真实场景挑战"，不展开背景综述。

### 第二层：难点（1 句，"然而…导致…同时…导致…"句式）

```
然而，xxx（现象1），导致xxx（难点1），同时，xxx（现象2），导致xxx（难点2）。
```

每点先说现象再说难点，两点用"同时"连接，不用分号或"一是/二是"。现象词与章引言 `\textit{}` 同族；两项难点须能从本段现实需求推出，各项工作的技术子句须能卡住这些根因。见 [section/consistency.md](../section/consistency.md)。

### 第三层：为此开展研究（1 句）

```
为此，本章开展【章题】研究。
```

章题与目录中的章标题一致，不加 `\textit{}`。一句话即可。

### 第四层：若干项工作（各项一句，首先/其次/最后）

```
首先，提出xxx，通过/利用xxx（技术），实现/达到xxx（效果），在xx任务上量化。
其次，提出xxx，通过/利用xxx（技术），实现/达到xxx（效果），在xx任务上量化。
最后，提出xxx，通过/利用xxx（技术），实现/达到xxx（效果），在xx任务上量化。
```

- 每项以"首先/其次/最后，提出xxx"开头，方法名紧跟（只用中文，不加英文缩写）
- 每项 2–3 个子句：技术 → 性质/效果 → 量化。技术子句须是该方法真正卡住难点根因的变换，与章引言工作句、该工作节合段同族
- 不展开方法细节
- 方法名在本章小结中至少出现一次

**量化写法**：

- 同时报绝对与相对：绝对在前，相对在后
- 标明任务名与指标名
- 不写"百分点"，直接写"x%"
- 最好是所有数据集的平均相对提升
- 若某方法在部分数据集最优、部分次优，报最优数据集的绝对值 + 相对提升，不回避次优处
- 若核心贡献在非准确率指标，须标明指标名
- 比较对象要明确："次优方法""最优自监督基线"等
- 若若干项工作用同一数据集与设定，首次写全，后项用"于同设定下"

### 第五层：为整体主题提供作用（1 句）

```
通过上述技术，本章为xxx（整体主题）提供/奠定/构建xxx（作用），为后续xxx、xxx与xxx（后续研究点的任务名）奠定xxx基础。
```

只写对整体主题的作用，不写"第~\ref{chap:xxx}~章"。后续研究点用任务名，不用章号。

## 常见问题

### Q：本章小结和本节小结有什么区别？

**本章小结**收束整章若干项工作，在 `\section{本章小结}` 下；**本节小结**收束单节一项工作，在 `\subsection{本节小结}` 下。本章小结须含"为整体主题提供作用"的收束句，本节小结不需要。

### Q：量化要不要报所有数据集的数字？

**不要。** 挑最有代表性的 1–2 个数据集报绝对值，再用所有数据集的平均相对提升收束。全部数据集的数字在实验分析节已有表格。

### Q：如果某方法在部分数据集不是最优怎么办？

如实处理。可报最优数据集的绝对值与相对提升，不回避次优处；也可只报平均相对提升。若核心贡献在非准确率指标，重点报该指标。

### Q：要不要写"验证了方法的有效性"？

**不写宾语泛泛的空话。** 量化数字本身就是证据。允许宾语落到具体机制的"说明/验证了……的有效性"。

### Q：末句要不要钩下一章？

**不写"第几章"。** 只需说明本章为整体主题提供什么基础，可用任务名简要提及后续研究点。章引言各章也不写承上句，本章小结同样不写"当关注点从 X 转向 Y"。

### Q：若干项工作时小结超 400 字怎么办？

**按压缩技巧精简，目标 300 字左右。** 六层结构不变，每层压短：

- **现实需求**：压到一句，只含"对象+意义"。
- **难点**：保留句式，每点压到"现象→难点"一笔带过。
- **各项工作**：技术描述精简到关键动词；量化部分，若用同一数据集与设定，首次写全，后项用"于同设定下"；省略重复的任务名。
- **为整体主题**：保持一句，不压缩。
