# 国内外研究现状

## 核心原则

**本章按各条线索写方法谱系与空白，用同一套柱名和难点现象词引出各工作章。** 每个小节固定四段：总体介绍、两类展开（末句“然而，”）、`\textbf{总结分析：}` 后用研究内容名收束到后文。好的研究现状让读者看见“谁做了什么、按什么分、在何条件下成立、卡在哪、本文接着做什么”，并且不足句能原词打回第一章难点。

节数与工作章一一对应；每节再分若干 `\subsection`（通常每柱三条线）。不要按发表论文清单排，也不要把绪论研究问题的缺口段再写一遍。

### 十一条铁律

1. **禁止成果简称、模块与公式；第四段可用研究内容名。** 正文方法名若出现，是前人工作。禁止预告本文各成果简称。各小节第四段允许“本文开展【研究内容名】研究”，A 与组织节 / 各工作章章题同一套。节末、章末只 `\ref` 后文，不复写“本文开展”，不写模块名。
2. **按各条线索，不按论文清单。** 各节标题 = 绪论各柱名 = 各工作章章题。每个小节第二、三段末句必须以“然而，”起句，并同时有【限制条件】+【机制原因】+【第一章已锁难点现象词】，不得另起近义，也不得只在段末甩一句难点词。
3. **相对绪论研究问题必须新增一层。** 绪论每柱约两段、少引、只写缺口；本章展开谱系，每个小节必须新增分类轴或代表机制，不得把缺口句拉长重贴。工作章预备知识给后文要用的公式与符号。节动机只挑 2–3 类最相关工作并写不足因果，不在此重复堆文献。
4. **每个 `\subsection` 固定四段。** 总体介绍（短）+ 一类展开（长）+ 另一类展开（长）+ 总结分析（短）。源论文 Related Work 若是三段，并入两组，不单开第三组。
5. **引用具体，禁止流水账。** 同一句 `\cite` 不超过 2 篇。选能代表路线发展或关键分歧的工作；连续 3 篇以上同机制合并为一句。禁止“方法名 + 半句贡献”逐篇点名。禁止“大量研究”“填补空白”“目前研究很少”“尚无人研究”。
6. **文献只来自对应源论文。** 以该小节对应成果的 Related Work 为唯一文献来源；无独立 RW 则用 Introduction。键优先工程已有 bib 与冲突清单；缺则从源 `.bib` 整条原样并入，不自造键、不从网上补元数据。
7. **小节标题与节内、绪论前后专名统一。** 方向名一旦锁定，不要写成近义变体。方程类型名（常微分方程、偏微分方程）可保留。
8. **第二、三段段首两套可选，同一小节不混。** 选用“第一类工作 / 另一类工作”，或“在 A 方面 / 在 B 方面”。润色不得改已选定的那一套，也不得改末句“然而，”和第四段 `\textbf{总结分析：}`。不要改成“一方面 / 另一方面 / 另一类工作则 / 转而”。本章四段骨架优先于 [polish/academic-zh.md](../polish/academic-zh.md) 的去同构。
9. **第二、三段打开写，有理有据。** 段内顺序：共同思路 → 代表工作 → 成立条件；最后一句“然而，”收束到难点。先写这类方法已经解决什么、在何设定下成立，再写失效；不做全称判断。
10. **工具谱系必须写清不可直接搬。** 并入第二或第三段末（“然而，”之前）时，写清任务目标、数据形式或评测为何不能直接适用。
11. **节末不复写“本文开展”；本章小结例外。** 节末收束两句以内：半句已覆盖 + `\ref` 后文章。本章小结按“现实需求→各方面→各柱两面难点→扣回需求”结构写：描述现有不足时方面名用领域通名，收束句才用完整研究内容名，不点成果简称。

## 对应链

写任何一节之前先锁柱名、该柱两点难点、该柱研究内容名（内部草稿，不写入 `.tex`）。表建不成，不要开始改句子。

| 前文 / 后文锁的东西 | 本章必须对上 |
|---|---|
| 绪论各条线索名 / 组织节研究内容名 / 各工作章章题 | 各节标题；第四段“本文开展 A 研究”的 A 原词同一套 |
| 绪论只收的缺口与 `\textit{}` 难点现象词 | 本章展开谱系并新增分类轴或代表机制；第二、三段“然而，”句原词打回 |
| 后文章引言两点难点 | 该节各小节的不足分别卡住这些难点；两项工作可打同一难点的不同层 |
| 后文关键变换（不写成果简称） | 第四段用机制通顺表述：输入、卡住哪一环、刻意不做什么 |
| 工作章预备知识 | 公式、符号、任务定义留给预备知识；本章不推导 |
| 节 `\subsection{研究动机}` | 此处给谱系；节动机只挑 2–3 类 |

**绪论与本章的差别：** 绪论每柱约两段，点名极少代表工作即收到缺口。本章同各柱，但每柱若干小节，每小节四段。相对绪论必须能指出新增的分类轴或代表机制。

## 章结构

```text
章首导语（各线索；主体写谱系，各小节第四段才收束到后文）
  → 每节导语（若干条线如何对着该柱难点）
    → 每个小节四段：
        第一段（短）总体介绍
        第二段（长）第一类工作 / 在 A 方面 → 末句“然而，”
        第三段（长）另一类工作 / 在 B 方面 → 末句“然而，”
        第四段（短）\textbf{总结分析：} + 本文开展【研究内容名】
    → 节末收束（已覆盖半句 + \ref 后文，不复写“本文开展”）
  → 本章小结（现实需求→各方面→各柱两面难点→扣回需求）
```

### 章首导语（`\chapter` 后、第一节前）

点明与第 1 章同一各条线索。主体写方法谱系；各小节第四段才用研究内容名收束到后文。

```
本章按【柱一名、柱二名、…】若干条线索综述既有工作，并简要分析现有研究的不足之处。
```

不在此写成果简称、模块或数字。不必强制回指“第 1 章把……收成几个科学问题”。

### 节导语（`\section` 后、第一个 `\subsection` 前）

一至三句，列出本节若干条线，并点出它们如何对着该柱难点。不要展开代表工作，不要写“本文开展”。

```
[本节对象一句话。]
既有工作可从 A、B、以及 C 若干条线综述，分别对应……。
```

### 每个小节（四段）

段与段之间空一行。第一、四段相对简洁；第二、三段打开写。同一小节的第二、三段只选一套段首，不混用。

**第一段（短，3–5 句）：总体介绍。** 该方向的概念或作用，以及与本柱难点的关系。传统背景若必须交代，压进本段。不要在此展开代表工作，不要写“本文开展”。

**第二、三段（长，各 8–12 句）：** 段首选用“第一类工作…… / 另一类工作……”，或“在 A 方面…… / 在 B 方面……”。段内顺序：

1. **共同思路。** 本类方法共同在做什么、按什么机制走。
2. **代表工作。** 中文重述源论文 RW，不逐句直译。只选能代表路线发展或关键分歧的工作；连续 3 篇以上同机制合并为一句，`\cite` 仍不超过 2 篇。
3. **成立条件。** 这类方法已经解决什么、在何设定下成立。不做“目前研究很少”式全称。
4. **末句必须以“然而，”起句。** 同一句写清【限制条件】+【机制原因】+【第一章已锁难点词】。不足动词用“较少 / 难以 / 不易”；尽量不用“仍少见 / 还不多见 / 仍然较少”。

```
第一类工作【共同思路】。
【代表：关键分歧或路线节点，同机制可合并。】
这类方法在【设定】下能够【已解决什么】。
然而，在【限制条件】下，【机制原因】，因而【难点词】。
```

如何切两类：取源论文 Related Work 的分类轴。源论文若是三段，把第三段并入第三段（“然而，”之前）作为工具谱系或表征手段。不要为“完整”单开第五段。工具谱系必须补一句：任务目标、数据形式或评测为何不能直接搬到本节对象上。

同一柱内避免各节重复同一段史前史：只在该柱第一个 `\subsection` 的第一段里用三至四句交代，后两节从本章设定起笔。

**第四段（短，2–4 句）：**

```
\textbf{总结分析：}【原词回收本小节卡住的难点，可兼及本柱另一难点。】
因此，本文开展【研究内容名】研究，通过【机制通顺表述】，提升【难点对应能力】。
```

约束：

- 段首必须是 `\textbf{总结分析：}`（LaTeX 加粗，不是 Markdown `**`）。
- A 与组织节 / 各工作章章题同一套，不另起近义。同一柱各小节的 A 可以相同；机制表述按本小节卡住的那一层写，不要各节抄同一句。
- 机制表述写成后文关键变换的通顺句（输入、卡住哪一环、刻意不做什么），不列模块名、不报数字、不写成果简称。
- “提升 xxx”必须落到已锁难点的缓解，禁止“显著提升 / 有效解决”。
- 主语用“本文”，不用“本章提出”。

### 节末收束

两句以内。先半句写本节若干条线已经覆盖什么，再 `\ref` 到后文对应章。不复写“本文开展”，不点成果简称。

### 本章小结

收束全章，按“现实需求→各方面→各柱两面难点→扣回需求”结构写。一段，逐句换行。

```
[现实需求一句：知识/数据分散在……，往往存在【锁定条件】，需要进行【研究目标】，把……整合成……。]
为此，本文主要关注【领域通名1、2、…】若干问题。
在【领域通名X】方面，现有研究由于【机制1】，造成【难点1】；并且由于【机制2】，造成【难点2】。
（其余各柱同此句式）
因此，围绕【研究目标】，本文开展【研究内容名A】【研究内容名B】……研究，在【锁定条件】下把……变成……。
后文第~\ref{...}~章至第~\ref{...}~章将围绕这几方面展开。
```

约束：

- **现实需求句要具体但简洁。** 不堆砌名词，也不抽象成口号。条件须按台账成对或整组使用。
- **各方面名用领域通名，不加本文特色限定词。** 描述现有工作不足时，方面名用现有工作所属的一般领域名，不加本文特色限定词（那些是本文特点，不是现有工作特点）。收束句“本文开展……研究”才用完整研究内容名（带本文特色限定词）。
- **每柱一句含两面难点。** 难点词原词打回第一章已锁具体难点，不另起近义。机制写现有工作的不足原因，不写本文做法。
- **收束拆两句。** 第一句扣回现实需求。第二句“后文第 X 章至第 Y 章将围绕这几方面展开。”用“这几方面”，不用“这几处空白”。
- 不点成果简称，不写模块名与数字。主语用“本文”。不复写各小节第四段的机制表述，只列研究内容名。

## 文献与引用

文献唯一来源是该小节对应源论文的 Related Work；无独立 RW 改用 Introduction 的两分法。辅源只用于给同一小节增厚谱系，不把未纳入本章的成果写成第三条线索。

**并入 bib 的步骤：**

1. 先查工程 bib 是否已有同键；再查冲突清单是否已有“原键 → 规范键”。已有则正文只用规范键。
2. 同文献被不同论文用了不同键时，正文改用规范键，不新增第二条。
3. 确认没有该文献后，从源 `.bib` **整条复制**：键名与字段保持原样，不改 title / author / year，不补 DOI。
4. 源键与已有键同名但文献不同，给新条目加最小后缀 `-2`，只改键名，并在冲突清单补一行。
5. 禁止：自造键、手写或网上拼条目、从非本小节源 bib 顺手引入无关文献、一次并入源 bib 全文。

正文：同一句并列引用不超过 2 篇；一句里多个 `\cite{}` 合计也不得超过 2 篇，须拆句。每篇被引文献须能看出贡献或局限。连续 3 篇以上同机制合并为一句。

## 常见问题

### Q：绪论已经写过空白，本章还要不要展开？

**要，且必须新增一层。** 绪论只收缺口。本章写谱系：谁做了什么、按什么分、在何条件下成立、卡在哪。每个小节要能指出新增的分类轴或代表机制。

### Q：源论文 Related Work 是三段，怎么办？

**并成两类，仍写四段。** 第三段并入本小节第三段（“然而，”之前）作为工具、表征手段或迁移桥。不要单开第五段。并入的工具谱系必须写清为何不能直接搬。

### Q：可以用“仍少见 / 还不多见”收束吗？

**尽量不用。** 第二、三段末句用“然而，”起句，不足动词用“较少 / 难以 / 不易”，并写清限制条件与机制原因，再扣难点词。

### Q：要不要出现本文成果简称？

**不要。** 正文与第四段都不点成果简称。第四段只写“本文开展【研究内容名】研究”，机制用通顺表述。引用键若会排出本文篇名，改用同类前人工作代表。

### Q：第四段的 A 同一柱各小节都一样，可以吗？

**可以。** 同一柱的 A 与章题 / 组织节条目标题对齐，各小节可以相同。机制表述必须按本小节卡住的那一层写，不要各节抄同一句。

### Q：公式和任务定义放哪？

**放工作章预备知识。** 本章可以点名某工具是做什么的，不写方程、不定义符号。

### Q：小节标题改了，正文要不要跟着改？

**要，前后统一。** 标题、节导语、第一段、第四段研究内容名、绪论对应句用同一专名。方程类型名不是方向名，不必改。
