# 中文学术润色：对照表

## 一、AI 腔模板句 → 推荐改法

### 1. 排比式内层包装（序号本身不改）

| 要改的内层套话 | 推荐改法 | 备注 |
|---|---|---|
| 一方面…不足在于 A。其原因是 B。另一方面…不足在于 C。其原因是 D。 | 保留“一方面/另一方面”，两边内层改成不完全同构的叙述 | 连接词是逻辑骨架 |
| 首先…其次…最后…通过这种方式… | **原样保留** | 方法步骤的逻辑骨架，禁止拆掉 |
| 一是…二是…三是… | **原样保留** | 分点逻辑骨架，禁止拆成散文 |
| 其一，…。其二，…。其三，…。 | 可换成一是/二是/三是以统一用词，**不得删除分点** | 实验段尤其要留序号 |

### 2. 贡献列举

| AI 腔（原文） | 推荐改法 | 备注 |
|---|---|---|
| 本节贡献有三：A；B；C。 | 本节做了 A，给出 B，并在 C 上验证。 | 融进方法预告 |
| 本节贡献有三：A；B；C。 | 本节将 A 以实现 B，在 C 上验证有效性。 | 更简洁 |
| 本节贡献有四：A；B；C；D。 | 本节 A，B，C，并在 D 上验证。 | 四条以上必须合并 |
| 具体贡献有四：A；B；C；D。 | 本节 A，B，C，D。 | 去掉"具体贡献有" |

### 3. 因果连接

| AI 腔（原文） | 推荐改法 | 备注 |
|---|---|---|
| 据此提出 X | 由此提出 X | 仅限段内；段首“在此基础上”不换 |
| 据此提出 X | 由此把 X | 用于"把"字句 |
| 据此把 X 分成 | 由此把 X 分成 | 简单替换 |
| 在此基础上，本节提出 X | **原样保留** | 研究动机合段段首，禁止改成“由此提出” |
| 为缓解上述问题，… | **原样保留** | 研究动机转段段首，禁止改成“要把……拆开” |

### 4. 判断句

| AI 腔（原文） | 推荐改法 | 备注 |
|---|---|---|
| 其核心是"先 A、后 B"的范式 | X 先 A、后 B | 用方法名做主语 |
| 其核心是把 A 引入 B | X 把 A 引入 B | 同上 |
| 其核心有二：A；B | X 以 A，以 B | 去掉"其核心有二" |
| 其本质是 A | A 实质上是… | 或直接陈述 |
| 其本质在于 A | A 的关键在于… | 视语境 |

### 5. 回指句

| AI 腔（原文） | 推荐改法 | 备注 |
|---|---|---|
| 这一观察是把…的依据 | 由此，…便有了依据 | 去掉"这一观察是" |
| 这正是…的机制依据 | 这解释了…的原因 | 更自然 |
| 这正是…的关键 | 这是…的关键所在 | 稍微调整 |
| 这正是前文局限 X | 这对应前文局限 X | "对应"比"正是"好 |
| 这正是…区别于…的根本所在 | 这正是…区别于…的根本所在 | 保留（单次使用可接受） |

### 6. 小结开头

| AI 腔（原文） | 推荐改法 | 备注 |
|---|---|---|
| 本节针对…问题，提出… | …（问题），本节提出… | 问题前置做主语 |
| 本节针对…的局限，提出… | …会…，本节提出… | 同上 |
| 本节针对…不足，提出… | …存在…不足，本节提出… | 同上 |
| 本节据此提出… | 由此提出… | 去掉"本节" |

**关键**：让 3–4 个小结换种开头，不要都从"针对…提出"起手。有的先报结果，有的先点局限。

### 7. 实验结果列举

实验段用“其一/其二/其三”或“一是/二是/三是”分点是正常写法，**保留序号**。若要改，只改每条内部的套话，不要把分点拆成无序号并列句。

### 8. 破折号、直角引号与行文

| AI 标记 | 推荐改法 | 备注 |
|---|---|---|
| 正文 `——` / `--` 插入语或举例 | 改为逗号，或“……，例如……” | 连字符仅留在英文复合词与数学式 |
| 正文 `「」` / `『』` | 改为中文双引号“……”或单引号‘……’ | 术语、专名用 `\emph{}` / `\texttt{}` |
| “转而”“值得注意的是”起句 | 删掉填充词，或改用该部分规定的段首连词 | 段首连词按各子文件骨架保留 |

`.tex` 须逐句换行、一句一意。段首连词按各子文件骨架保留。正文不用直角引号。

### 9. 相关工作章四段骨架

| 锁死 / 要改 | 做法 | 备注 |
|---|---|---|
| 已选段首“第一类工作 / 另一类工作”或“在 A 方面 / 在 B 方面” | **原样保留** | 同一小节不混；不得改成“一方面 / 另一类工作则 / 转而” |
| 第二、三段末句“然而，” | **原样保留句首** | 句内补限制条件 + 机制 + 难点词 |
| 第四段 `\textbf{总结分析：}` | **原样保留** | 不要改成“本节针对…提出” |
| 第四段“本文开展【研究内容名】” | **原样保留** | 不是 AI 腔；机制保持通顺表述，不补成果简称 |
| 当前稿台账锁词、`\cite` 键 | **原样保留** | 去味不换近义、不改键 |
| 方法名 + 半句贡献，连续 3 篇以上同机制 | 合并为一句，`\cite` 仍 ≤2 | 不删已选段首 |
| ……仍少见。难点词。 | 末句改为“然而，在【限制条件】下，【机制原因】，因而【难点词】” | 不足动词用较少 / 难以 / 不易 |
| 填补空白 / 目前研究很少 / 尚无人研究 / 大量研究 | 删或改成有条件的“难以 / 较少” | 综述禁用 |
| “首次 / 率先”断言空白 | 改为有条件的不足 | 可核历史事实可留 |

## 二、中文学术规范用语（严禁修改）

### 公式释义

```
式中，X 为…；Y 为…；Z 为…。
```

这是国标公式释义格式，不是 AI 腔。全文统一用"式中"是对的，不要改成"其中"或英文式 where。

### 学术引用

```
沿用既有工作~\cite{…}
沿用~\cite{…}的约定
沿用~\cite{…}的训练、验证与测试集划分
```

中文学位论文综述里常用，表示"照用前人设定"。不是 AI 腔。

### 主语

```
本节/本章/本报告
```

主语用"本节""本章"而非"我们"，正是中科院抽检点名要避免"我们"之后的正确写法。不要改成"我们提出"。

### 数据陈述

```
在…上达…
相对…提升…
较…提升…个百分点
```

实验结果的标准报告句式。盲审要的就是这种干写法。

### 图表引用

```
如图~\ref{…}所示
如表~\ref{…}给出
图~\ref{…}给出…的示意
```

图表引用的标准句式，不是 AI 腔。

### 逻辑骨架（分点、递进、收束）

```
一方面…另一方面…
一是…二是…三是…
其一…其二…其三…          （实验段尤其保留）
首先…其次…最后…
先…，再…，最后…
通过这种方式，…
为缓解上述问题，…         （研究动机转段段首）
在此基础上，本节提出…     （研究动机合段段首）
为……可以分为两个方面。   （研究动机承段段首）
一类工作……               （相关工作章可选段首）
另一类工作……
在 A 方面……
在 B 方面……
然而，……                 （相关工作章第二、三段规定末句）
\textbf{总结分析：}……    （相关工作章第四段段首）
因此，本文开展……研究     （相关工作章第四段收束，不是 AI 腔）
```

这些是提升论证层次的连接词，不是 AI 腔。润色时**连包装词一起保留**。真正要改的是分点内部的同构套话，以及相关工作章段内的流水账与弱全称不足句。

### 承上启下

```
第X节……，实现……。然而，……。因此，本节……
```

节动机的承上不是 AI 腔，去味时不要删。章引言各章第一句都不承上，从现实需求起笔；不要改成“当关注点转向…”或补“第 X 章给出……”。

## 三、频率阈值参考

| 模式 | 全文允许上限 | 说明 |
|------|-------------|------|
| 一方面/另一方面、一是/二是/三是、首先/其次/最后、通过这种方式 | **不限制** | 逻辑骨架，禁止为去 AI 味而删 |
| 其一/其二/其三（实验段） | **不限制** | 正常分点 |
| 本节贡献有三 | 1 处 | 最好全部改掉 |
| 据此提出 | 1 处 | 偶尔用无妨 |
| 其核心是 | 1 处 | 偶尔用无妨 |
| 这正是 | 2 处 | 真正需要强调回指时保留 |
| 本节针对…提出 | 不限制总数，但开头句式至少 3 种变化 | 关键是句式多样性 |
| 第一类工作 / 另一类工作，或在 A/B 方面（相关工作章已选段首） | **不限制，且不得改写** | 同一小节只保留一套 |
| 相关工作章末句“然而，”、`\textbf{总结分析：}`、本文开展【研究内容名】 | **不得改写** | 四段骨架，不是 AI 腔 |
| 仍少见 / 还不多见 / 仍然较少 | 尽量 0 处 | 改为较少 / 难以 / 不易，并补条件与机制 |
| 填补空白 / 目前研究很少 / 尚无人研究 / 大量研究 | 0 处 | 综述禁用 |

## 四、处理优先级

按以下优先级处理（从高到低）：

1. **每节都出现的包装套话**（“本节贡献有三”“据此提出”“其核心是”）——每章留 1–2 处，其余换说法或删
2. **每节小结的同一句式**——让 3–4 个小结换种开头
3. **分点内部的同构套话**——保留“一方面/另一方面”“一是/二是”，只改“不足在于 + 其原因是”
4. **回指句**——"这正是""这一观察是"换成"这解释了""由此"或直接删
5. **正文破折号、直角引号与过长单句**
6. **相关工作章段内流水账与弱全称**——压缩同机制清单；把“仍少见。难点词。”改成末句“然而，”+ 条件 + 机制 + 难点词。不改已选段首、`\textbf{总结分析：}` 和“本文开展【研究内容名】”

公式释义、图表引用、数据陈述、段首连词、以及逻辑骨架**不要动**，动了反而失分。章引言各章从现实需求起笔。泛泛的“验证了本方法的有效性”要改；宾语落到具体机制的可留。不改数字、比较口径、文献主张、`\cite` 键和当前稿台账锁词。
