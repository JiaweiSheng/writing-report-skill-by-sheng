# 中文学术论文润色

## 核心原则

**润色做两件事：去掉内层包装套话，并守住中文学术报告体例。** AI 味不是某个词的问题，而是内层包装套话重复的问题。“本节贡献有三”“其核心是”“不足在于 + 其原因是”反复出现才是 AI 腔。`一方面/另一方面`、`首先/其次/最后`、`通过这种方式`、`一是/二是/三是` 即使全文多用，也是论证需要的逻辑骨架，不是去味对象。

### 六条铁律

1. **只改重复的模板句，不改中文学术规范用语**（公式释义、图表引用、数据陈述、承上启下等）
2. **每类模板句全文保留 1–2 处即可**，其余换说法或删除——不要把所有实例都改掉，否则反而失分
3. **逻辑骨架严禁删除**：`一方面/另一方面`、`首先/其次/最后`、`通过这种方式`、`一是/二是/三是`（以及实验段的`其一/其二/其三`）是提升论证层次的连接词，不是 AI 腔。去味时只改内层包装套话，不要把分点与递进拆成无序号散文
4. **段首连词严禁改写**：研究动机四段的段首“然而 / 因此”“为……可以分为两个方面”“为缓解上述问题”“在此基础上”是起承转合定位，不得改成“要把上述纠缠拆开”“由此提出”“转而”。相关工作章已选段首（“第一类工作 / 另一类工作”或“在 A 方面 / 在 B 方面”）、第二三段末句“然而，”、第四段 `\textbf{总结分析：}` 同样锁死。去味只动段内，不动段首。相关工作章四段骨架优先于去同构。
5. **改写门禁：** 不改数字、比较口径、文献主张、`\cite` 键、当前稿台账中的锁词（柱名、难点现象词、研究内容名、条件术语、对象句、应用名、互为依据句等）。缺出处标【待核】，不补造。相关工作章不得补入成果简称。
6. **连词真实性：** 检查“因此 / 从而 / 进而”前后是否真有转折或因果；一句里多个“通过 / 从而 / 进而”先拆句。相关工作章第二、三段规定末句“然而，”不改。不因此去改已选段首。

## 守中文学术报告体例

去味的另一半是**不要改成不像论文 / 报告**。中文学位论文与出站、结题一类研究报告有固定体例，改掉反而失分。

1. **主语：** 章内用“本章 / 本节”；绪论与结论可用“本文 / 本报告”。禁止“我们提出”。禁止用“本文提出”指代某一章的方法。
2. **公式：** 编号公式后用“式中，X 为……”，不要改成“其中”或 where。
3. **图表与数据：** “如图/表~\ref{…}所示/给出”；“在…上达… / 相对…提升…个百分点”。不要改成口语。图表字号略小于正文，至少为 `\small`。
4. **翻译腔：** 长定语拆短句；删“值得注意的是 / 总之 / 综上所述”等句首填充；被动改主动；术语首次“中文（English）”，此后用中文。同一节已锁定的术语不得为去味而换成近义词。工作节术语锁见 [section/consistency.md](../section/consistency.md)。
5. **空话与绝对化：** 删“显著提升、有效解决、全面系统”一类无数字的评价；“显而易见”改为“实验结果表明”；不利结果如实写。禁止“验证了本方法/本章方法的有效性”；允许“说明/验证了……的有效性”仅当宾语是具体机制。
6. **禁止元表述：** 不要写“源论文 / 小论文 / 为避免拼接感”。
7. **段首句与逻辑骨架：** 与 [研究动机](../section/1-motivation.md) 一致，研究动机四段段首不得改写；与 [related-work.md](../chapter/related-work.md) 一致，相关工作章已选段首、末句“然而，”、`\textbf{总结分析：}` 不得改写。“一方面 / 一是 / 首先 / 通过这种方式”不拆。第四段“本文开展【研究内容名】”不是 AI 腔，不要改成“本节针对…提出”。
8. **逐句换行、一句一意：** `.tex` 一句一行；过长单句、一串分号、一句里两个“从而”的拆开。
9. **正文不用破折号：** `——`、`--` 改为逗号或“例如……”。不要用“转而”“值得注意的是”起句。
10. **正文不用直角引号：** `「」`、`『』` 改为中文双引号“……”或单引号‘……’。术语、专名用 `\emph{}` / `\texttt{}`。
11. **综述禁用：** 填补空白、目前研究很少、尚无人研究、大量研究。相关工作章不足用“较少 / 难以 / 不易”且带条件与机制；尽量不用“仍少见 / 还不多见”。“首次 / 率先”只用于可核历史事实，不用于断言空白。

词汇级必删（换成具体数字或列举）：显著提升、全面系统、有效解决、重要意义、鲁棒性好、新颖方法、大量研究、大幅提升、近年来、越来越多的、发挥重要作用、填补空白、目前研究很少、尚无人研究。

## 相关工作章专条

润相关工作章时先读 [related-work.md](../chapter/related-work.md)。每个小节固定四段。下列项**严禁改写**：

| 锁死项 | 禁止改成 |
|---|---|
| 已选段首“第一类工作 / 另一类工作”或“在 A 方面 / 在 B 方面” | “一方面 / 另一方面 / 另一类工作则 / 转而” |
| 第二、三段末句“然而，” | 删掉“然而，”或改成“因此 / 转而” |
| 第四段 `\textbf{总结分析：}` | “本节针对…提出”、去掉加粗 |
| 第四段“本文开展【研究内容名】” | 改成成果简称，或改成“本节针对…提出” |
| 当前稿台账中的难点现象词、柱名、研究内容名 | 近义改写 |
| `\cite` 键、文献主张、数字与比较口径 | 换键、补造、改口径 |
| 成果简称（本来就不该出现） | 补进本文方法简称 |

段内可改：流水账压缩为同机制合并；“仍少见 / 还不多见”改为“较少 / 难以 / 不易”，并保证末句“然而，”含【限制条件】+【机制原因】+【难点词】。

## 工作流程

### 第一步：扫描全文，定位模板句

用 Grep 搜索以下模式，并检查直角引号，统计每类出现次数和具体行号：

```
# 1. 分点内层包装套话（序号本身不搜、不删）
不足在于|其原因是

# 2. 贡献列举
本节贡献有三|本节贡献有四|贡献有三|贡献有四|贡献有五

# 3. "据此提出"
据此提出|据此把

# 4. "其核心是"判断句
其核心是|其核心有二|其本质是|其本质在于

# 5. "这一观察是…的依据"
这一观察是|这正是.*的依据|这正是.*的关键

# 6. 小结模板开头
本节针对.*提出|本节据此

# 7. 过度对称的内层对照（人工判断；一方面/另一方面本身不删）

# 8. 直角引号（正文禁用，改为“”或‘’）
「|」|『|』

# 9. 综述弱全称（相关工作章优先改成“较少/难以/不易”+条件+机制）
仍少见|还不多见|仍然较少|目前研究很少|尚无人研究|大量研究|填补空白

# 10. 连词堆叠与去模板化（检查相邻句是否反复开头；一句多个则拆）
通过|从而|进而
```

### 第二步：逐类处理

对每类模板句，按以下策略处理：

| 策略 | 适用场景 | 示例 |
|------|----------|------|
| **换序号词（可选）** | "其一/其二/其三" 可换成 "一是/二是/三是"，但**不得删掉分点** | 仅当用词不统一时 |
| **去掉编号** | "本节贡献有三：A；B；C" → "本节做了 A，给出 B，并在 C 上验证" | 仅针对“贡献有三”包装，不针对一是/二是 |
| **换连接词** | 段内的"据此提出" → "由此提出"；**段首“在此基础上”“为缓解上述问题”、相关工作章已选段首与末句“然而，”不换** | 因果连接 |
| **换主语** | "其核心是X" → "X 先…后…"（用方法名做主语） | 判断句 |
| **改陈述** | "这一观察是…的依据" → "由此，…便有了依据" | 回指句 |
| **问题前置** | "本节针对…提出…" → "…（问题），本节提出…" | 小结开头 |
| **直接删除** | 删掉回指句的"这正是"部分，让逻辑自己接 | 回指句 |

### 第三步：保留不动的部分

以下属于中文学术规范用语，**严禁修改**：

- `式中，X 为…；Y 为…` — 公式释义标准格式
- `沿用既有工作` / `沿用~\cite{…}` — 学术规范用语
- `本节/本章/本报告` 做主语 — 避免第一人称的正确写法
- `在…上达…` / `相对…提升…` — 数据陈述标准句式
- `如图/表~\ref{…}所示/给出` — 图表引用标准句式
- `一方面…另一方面…` — 两类对照的逻辑骨架，保留
- `一是…二是…三是…` / 实验段 `其一…其二…其三…` — 分点列举的逻辑骨架，保留
- `首先…其次…最后…` / `先…，再…，最后…` — 方法步骤的逻辑骨架，保留
- `通过这种方式，…` — 步骤收束的逻辑骨架，保留
- `为缓解上述问题` / `在此基础上` / `为……可以分为两个方面` / 段首`然而` `因此` — 研究动机段首连词，原样保留
- 相关工作章已选段首、末句`然而，`、`\textbf{总结分析：}` — 原样保留
- 第四段“本文开展【研究内容名】” — 不是 AI 腔
- 当前稿台账锁词、`\cite` 键 — 去味不换近义、不改键、不补成果简称
- 承上启下 — 节动机的承上不是去味对象。章引言各章第一句都不承上，从现实需求起笔
- 数字、比较口径、文献主张 — 原样保留；缺出处标【待核】，不补造

### 第四步：编译验证

改完后编译一次，确认无 LaTeX 错误：

```bash
xelatex -interaction=nonstopmode Thesis.tex
```

## 7 类 AI 腔详解

### 1. 排比式内层包装，不是序号本身

**真正的 AI 腔**：每条分点都套同一套内层句式（“不足在于…。其原因是…。结果是…”两边各来一遍），且三条字数差不多。

**不是 AI 腔、必须保留**：`一方面…另一方面…`、`一是…二是…三是…`、`首先…其次…最后…`、`通过这种方式，…`、实验段的 `其一…其二…其三…`。

**改法**：只改内层包装套话，分点序号原样留下。“其一”与“一是”可互换以统一用词，但**不得拆成无序号散文**。

### 2. “本节贡献有三/四/五”

**特征**：几乎每节动机收尾都是"本节贡献有三：A；B；C"。

**改法**：融进方法预告："本节做了 A，给出 B，并在 C 上验证"；或直接陈述。删掉"贡献有三"四个字。

### 3. “据此提出”“据此把”

**特征**：因果连接词"据此"高频出现。

**改法**：段内、非段首的"据此提出" → "由此提出" / "由此把"。段首“在此基础上，本节提出”**原样保留**。

### 4. “其核心是”“其核心有二”

**特征**：每提一个方法就来一句"其核心是…"。

**改法**：删掉"其核心是"，直接用方法名做主语："【方法名】先 A、后 B"。或改成"X 的要点是…" / "X 的做法是…"。

### 5. “这一观察是…的依据”“这正是…”

**特征**：回指句做强调。

**改法**："这一观察是把…的依据" → "由此，…便有了依据"；"这正是…的机制依据" → "这解释了…的原因"。

### 6. 小结模板“本节针对…提出…”

**特征**：每节小结都是"本节针对…问题，提出…。"

**改法**：把问题前置做主语："…（问题），本节提出…"。让 3–4 个小结换种开头。

### 7. 过度对称的内层对照，不是“一方面/另一方面”

**真正的 AI 腔**：二分之后两边内层句式完全同构。

**不是 AI 腔、必须保留**：`一方面…另一方面…` 本身。表格式对照同样保留。相关工作章已选段首不是去味对象。第四段“本文开展【研究内容名】”也不是去味对象。

**改法**：保留二分连接词，只把两边内层改成不完全同构的叙述。不要改成“转而”“另一类工作则”。
