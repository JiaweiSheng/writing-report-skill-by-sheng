# “研究动机”撰写

## 核心原则

**研究动机不是文献综述的缩写，而是“起承转合”四段叙事，回答三个问题：本节做什么、为什么现有方法不够、本节从什么角度切入。** 好的动机段让读者在 400–800 字内理解任务的来龙去脉，并记住一个核心切入点。

节动机与章引言分工不同：章引言是全章路线图（两点难点 + 若干项工作），各章第一句都不承上；节动机只讲这一节。不要把“当关注点从 X 转向 Y”套进节动机。

### 七条铁律

1. **承上写作用，不写机制**：除章首节外，开头必须承接上一节，但只点“已经解决了什么问题”，不复述公式、稳定性证明、基底名称。用“然而”转到本节缺口。
2. **任务落到章里的缺口**：写清做什么、做成了给谁用、缓解全章哪一难。不要停在评估协议。
3. **不足有据、分组有目的**：批评须引用具体工作；分组前先写“为什么要分”。组内标记可以是“一方面 / 另一方面”，也可以是“一是 / 二是 / 三是”。每条不足直接写因果链，不贴“不足在于 / 其原因是”标签。
4. **转段给新思路，并留下难点**：提出本节方法前，先给出一个新视角或工具，再写清它仍解决不了什么。有难点才能引出合段的方法。难点不必再拆成一是 / 二是。
5. **四段段首句保持稳定**：每段用固定骨架的段首句定位功能。润色、去 AI 腔时只改段内叙述，不得改写段首句。
6. **术语与对应链服从整节锁。** 任务名、难点现象词、机制作用词与章引言、后文方法/实验/小结同一套。起段用途钩现实需求，承段后果钩难点根因，合段变换须是读懂方法之后的关键变换。正文不写挑战编号。细则见 [consistency.md](consistency.md)。
7. **行文遵守入口通则。**

## 起承转合四段

四段对应五步：起 = 承上 + 任务；承 = 途径 + 不足；转 = 新思路 + 仍有难点；合 = 方法提出 + 收束。

**每段段首句（写完后不得改写）**：

| 段 | 功能 | 段首句骨架 |
|----|------|------------|
| 起 | 上一节作用 → 缺口 → 本节任务与用途 | “第 X 节……，实现……。然而，……。因此，本节……” |
| 承 | 实现途径一句；再按目的分组批评 | “……是实现该目标的常用途径，……。为……，现有研究主要可以分为……。” |
| 转 | 新思路有何用；仍然存在哪些难点 | “为缓解上述问题，……（新思路）。然而，……并不能直接……（难点）。” |
| 合 | 提出方法；各点如何分别回应不足 | “在此基础上，本节提出……。” |

**段内再衔接**（可按节选择，选定后本段统一）：
- 承：重点是分组。可用“一方面 / 另一方面 / 此外”，也可用“一是 / 二是 / 三是”，或“第一 / 第二 / 第三”。
- 转：不强制分点。用一两句话写清“新思路仍过不了哪一关”即可。
- 合：“首先 / 其次 / 最后 / 通过这种方式”。点数对齐承段不足，不必固定为三。

**段首句禁忌**：不要连用两次“针对上述问题”。转段首用“为缓解上述问题”，合段首用“在此基础上，本节提出”。不要用“既有工作大致分成两条线”起承段。去味只动段内包装套话，段首句原样保留。

**起段与承段的边界**：实现途径放在承段首句，不要垫在起段末尾。起段只负责“前几节做了什么 / 本节做什么、给谁用”。

## 五步结构

### 第一步：承上（1–2 句）

**段首句**：“第 X 节……，实现……。然而，……。因此，本节……”

上一节的贡献用**作用**概括，不用机制细节。

| 宜 | 忌 |
|----|----|
| “第 X、Y 节从架构层面改进了……，实现……” | 把上一节的公式再写一遍 |

**章首节写法**（本章第一节）：
- “本章沿……展开。本节作为第一条路线，把……落在……上”

**预备知识后的第一节写法**：若章引言后紧跟预备知识节，第一个工作节可不必承接章引言的挑战，直接从本节任务出发。起段用"总—分"结构：首句总起本节做什么，缺口句点现状，第三句带视角具体化。

```
本节从……出发，探索……，为……奠定基础。当前，既有方法……。因此，本节从……视角出发，探索……，为……奠定基础。
```

缺口句描述现状时用"当前"引出，比"然而"更自然；"然而"留给更强转折。不要用造句式"当关注点从 X 转向 Y"。追问可以融入任务句，不必单列"本节追问：……"。

### 第二步：任务定义（2–4 句，并入起段后半）

给出任务，并接到章里的那个缺口。

- 写“预训练 / 学习 → 得到可用表征 → 用于下游 → 缓解何难”，不要停在评估协议。
- 任务落脚可用"以缓解……难点"，也可用"为……奠定基础"。落脚所用难点现象词必须与章引言 `\textit{}` 同族。
- “缓解何难 / 给谁用”须能回到章引言现实需求的对象，不要只写实验室协议。
- 用文字描述流程，不保留形式化符号（留给方法设计节）。
- 可暗示方法方向，但途径的完整定义放到承段首句。
- 主语用“本节”，不用“本文”。
- 避免“进而……然后再……进而”叠用。

### 第三步：既有方法回顾与不足分析（承段）

**段首句**：“……是实现该目标的常用途径，……。为……，现有研究主要可以分为……。”

| 情况 | 组织方式 |
|------|----------|
| 方法按路线分组 | “为……，现有研究主要可以分为两个方面。一方面……。另一方面……。此外，……” |
| 方法列 N 点不足 | “……仍存在三点不足。一是……。二是……。三是……” |
| 方法分两类范式 | “【范式甲】（english-name）……；【范式乙】（english-name）……。然而，两种范式均未……” |
| 范式转换 | “既有方法多在……，再以……。这种做法关注……，却容易盖过……” |

**分组规则**：重点是分组，不绑定某套序号。先写分组目的，再分组。组名用课题名词。分组标记后直接接做法或缺陷。若有共同根因，用“此外，上述方法还……”收束；范式分组的共同根因句可用"然而"。

**每条不足的因果链**（直接陈述，不贴标签）：

```
[方法名与做法] → [机制上为何会这样] → [导致什么]
```

不要写成“不足在于……。其原因是……。结果是……”。

**术语**：方法名、损失名保留英文。复合英文范式名先给中文翻译再括英文原文。现象用中文说清即可。后文若用简称，须在承段先落地。少用破折号插入例子。

不足条数 2–3 条，超过 3 条应合并。每条配引用或反例。此步不放表和公式。

### 第四步：切入角度（转段）

**段首句**：“为缓解上述问题，……（新思路）。然而，……并不能直接……（难点）。”

写法：新物理类比 / 新数学工具 / 新分解视角 / 范式转换。

“转”只要求两层：新思路能做什么；它仍解决不了什么。不要把新思路写成“这样一来问题就解决了”。方法名留到合段。不写证明过程，不列实例化名称。难点可以落到求解层，但不在转段展开对策。

若本节工具在另一章出现过，须显式点明：“第 X 节已将……用于……；本节将其作用对象由‘……’转为‘……’”。

### 第五步：方法提出与收束（合段）

**段首句**：“在此基础上，本节提出 X（英文全称，简称）。”

```
在此基础上，本节提出 X（英文全称，简称）。首先，……。其次，……。最后，……。通过这种方式，……。本节在……上……；相对……提升……，表明……
```

- 方法名在此处正式登场，后文用简称。主语用“本节提出”。
- “首先 / 其次 / 最后”对齐不足。作用词来自读懂方法之后的关键变换，须与后文模块收束同词。
- “通过这种方式”只写机制结果。该机制作用词锁定后，方法收束、实验结论、小结效果必须沿用。
- 可报与机制相关的 1–2 个关键数字。不要写泛泛的“验证了方法的有效性”。
- 不展开算法流程。
- 合段写完后自问：去掉这些变换，章引言难点的哪句根因会继续成立？

## 定稿骨架（占位）

**起**：第 X、Y 节改进……，实现……。然而【缺口】。因此本节关注……，以缓解【章难点】 / 为……奠定基础。

**承**：【途径】是常用途径。为【目的】，现有研究分两个方面。一方面……（引用）。另一方面……。此外 / 然而，共同根因……。

**转**：为缓解上述问题，【新思路】能……。然而，并不能直接……。

**合**：在此基础上提出【方法名】（全称，简称）。首先……；其次……；最后……。通过这种方式【机制作用词】。实验报 1–2 个与机制相关的数字。

**预备知识后第一节**：起段用总—分，缺口用“当前”，第三句带视角。

## 特殊情况

### 章首节的承上

改为承接章引言：“本章沿……展开。本节作为第一条路线，把……落在……上”

### 预备知识后的第一节

直接从本节任务出发，总—分结构。非第一个工作节在承段末尾点明上述不足造成的后果，以流畅语言收束，不显式引用章引言编号或挑战名。写法："……均未……，使/造成/导致……难以……"。后果词须与章引言难点现象、现实需求同族。

### 共享工具的跨章关联

必须显式写明：“第 X 节已将……用于……；本节将其作用对象由‘……’转为‘……’”。这是把多篇论文收成一篇研究报告、而不是章节拼盘的关键。

### 范式转换节

先指出上一节范式的局限，再给出新范式的核心对比。可配一张范式对比图。

### 工业应用节

承上句点出从学术到工业的转换。用平台统计数据支撑难点。不足分析聚焦“既有方法未针对此场景定制”。

## 常见问题

### Q：动机段要不要展开方法细节？

**不要。** 公式推导、模块结构、算法流程留给方法设计节。

### Q：不足分析要不要覆盖所有现有方法？

**不要。** 挑与本节最相关的 2–3 类即可。全面回顾留给相关工作章。

### Q：动机段要不要配图？

**按需。** 任务示例图或范式对照表有用；方法框架图留给方法设计节。

### Q：切入角度和方法提出要不要分开写？

**要。** 转是“新思路是什么、它仍过不了哪一关”，合是“具体叫什么、各点如何回应不足”。

### Q：承段分组用“一方面”还是“一是 / 二是 / 三是”？

**均可，重点是分组。** 选定后本段统一。

### Q：转段一定要写“一是 / 二是”吗？

**不必。** 难点用“然而”说清楚即可。

### Q：润色时能不能改四段段首句？

**不能。** 去 AI 腔只改段内包装套话。锁定术语同样不能为去味而换成近义词。

### Q：怎么保证本项成果对应到章难点和现实需求？

**先读懂方法，再写合段，不要先写“回应挑战一”。** 细则见 [consistency.md](consistency.md)。

### Q：动机段要不要报实验数字？

**可报与机制相关的 1–2 个数**，细表留给实验节与本节小结。
